## How it works

This project is an on-chip ROM holding the 128 twiddle factors of the ML-KEM (FIPS 203) Number Theoretic Transform.
Entry k is 17^BitRev7(k) mod 3329, stored in Montgomery form (multiplied by 2^16 mod 3329) so it can feed a
Montgomery modular multiplier directly. The table is generated by a script and synthesized into standard-cell logic,
so there is no memory macro and nothing has to be loaded at start-up.

The 7-bit address on `ui_in[6:0]` is registered, the ROM output is registered, and the 12-bit value appears on
`uo_out[7:0]` (bits 7..0) and `uio_out[3:0]` (bits 11..8) two clock cycles after the address is applied.

## How to test

Hold `rst_n` low for a few cycles, then release it. Set `ui_in[6:0]` to an address k and read the 12-bit value
two clocks later. Expected values: k = 0 gives 2285, k = 1 gives 2571, k = 2 gives 2970, k = 3 gives 1812.
